# Support

## Where to get help

- **Documentation:** start with the [developer documentation](https://developers.hydraone.app), then [Troubleshooting](https://developers.hydraone.app/help/troubleshooting) and the [FAQ](https://developers.hydraone.app/help/faq).
- **Questions and ideas:** open a GitHub issue, or email <info@vtechcom.org> for anything that is not a bug.
- **Bugs:** open an issue with the bug report template. Include the SDK version, your framework and browser, and a minimal reproduction. Run `checkBridgeHealth` and attach the report after removing addresses and tokens.
- **Feature requests:** open an issue with the feature request template and describe the use case first.
- **Security problems:** do not use public issues. Follow [SECURITY.md](./SECURITY.md).

## What is supported

The latest release gets fixes. See the [versioning policy](./README.md#versioning-and-support) and the [CHANGELOG](./packages/core/CHANGELOG.md). Wallet extension bugs and HydraOne host application issues belong to those projects.

## Response expectations

This is an open source project maintained on a best-effort basis. There is no guaranteed response time for issues and questions.
