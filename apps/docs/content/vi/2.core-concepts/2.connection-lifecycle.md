---

`WalletBridgeClient` là lớp trung tâm. Bạn đưa cho nó một `appCenterOrigin` (embedded mode) hoặc `fallbackToExtension: true` (standalone mode), rồi gọi `init()`.

```ts
import { WalletBridgeClient } from '@hydraone/sdk';

const client = new WalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app',
  fallbackToExtension: true,
});

await client.init();
```

## Kết nối được chọn thế nào

| Game chạy ở đâu                                  | `init()` làm gì                                                                                                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Trong iframe** (nhúng trong App Center)        | Gửi `CLIENT_READY` qua transport và chờ host xác nhận. Chế độ này bắt buộc có transport (hoặc `appCenterOrigin`).                                      |
| **Ngoài iframe**, `fallbackToExtension: true`    | Phát hiện các extension ví trên `window.cardano`, chọn `preferredWallet` nếu đã cài (nếu không thì ví đầu tiên tìm thấy) và làm việc trực tiếp với nó. |
| **Ngoài iframe**, không có `fallbackToExtension` | Bị reject với `ERR_NOT_IN_IFRAME`.                                                                                                                     |

::note
Gọi `init()` nhiều lần là an toàn. Nó resolve ngay khi client đã kết nối và dùng chung một handshake đang chạy.
::

## Trạng thái kết nối

Đọc trạng thái bất cứ lúc nào:

- `client.connectionState`: `'disconnected' | 'connecting' | 'connected' | 'error'`
- `client.isConnected`
- `client.hostInfo`: thông tin host báo cáo trong lúc handshake

Các hook của React và composable của Vue cung cấp cùng trạng thái này dưới dạng giá trị reactive.

## Giải phóng client

Gọi `client.destroy()` khi game tắt. Nó gỡ listener, hủy các timer đang chờ và giải phóng transport. Transport mà client tự tạo từ `appCenterOrigin` sẽ bị hủy cùng với nó; transport bạn truyền vào thì bạn tự quản lý.
