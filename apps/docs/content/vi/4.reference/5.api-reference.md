---
title: "Tham chiếu API"
description: "Mọi export public của SDK theo từng entry point, và cách tạo tài liệu TypeDoc đầy đủ."
---

Tài liệu tham chiếu API đầy đủ được tạo từ các comment TSDoc trong `packages/core/src/` bằng TypeDoc. Nó không được commit vào repository, nên hãy build cục bộ từ thư mục gốc của repository:

```bash
pnpm run docs:api
```

Kết quả được ghi vào `packages/core/docs/api/`. Mở `packages/core/docs/api/index.html` trong trình duyệt. Tài liệu bao gồm ba entry point của `@hydraone-sdk/core`: `.`, `/react` và `/vue`.
