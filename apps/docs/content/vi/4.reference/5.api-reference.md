---
title: "Tham chiếu API"
description: "Tạo tài liệu tham chiếu API đầy đủ bằng TypeDoc từ các comment TSDoc của SDK."
---

Tài liệu tham chiếu API đầy đủ được tạo từ các comment TSDoc trong `src/` bằng TypeDoc. Nó không được commit vào repository, nên hãy build cục bộ:

```bash
pnpm run docs:api
```

Kết quả được ghi vào `packages/sdk/docs/api/`. Mở `docs/api/index.html` trong trình duyệt.
