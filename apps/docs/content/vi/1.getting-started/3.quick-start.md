Trang này đưa bạn từ một package đã cài đến một giao dịch đã ký. Nếu chưa cài SDK, hãy bắt đầu với [Cài đặt](/vi/getting-started/installation).

## 1. Tạo client

```ts
import { WalletBridgeClient, HydraBridgeError } from '@hydraone-sdk/core';

const client = new WalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app',
});
```

- `appCenterOrigin` là origin của App Center đang nhúng game của bạn. Client tự tạo và sở hữu `PostMessageTransport` cho bạn.

## 2. Kết nối và đọc dữ liệu

```ts
try {
  await client.init();
  const [address] = await client.getUsedAddresses();
  const balance = await client.getBalance();
  console.log(`Connected as ${address}, balance:`, balance);
} catch (err) {
  if (err instanceof HydraBridgeError) {
    console.error(`[${err.code}] ${err.message}`);
  }
}
```

::note
`getBalance()` trả về danh sách asset (`{ unit, quantity }`). Các helper cho React và Vue đọc lovelace giúp bạn; xem [Thao tác với ví](/vi/guides/wallet-operations).
::

## 3. Ký và gửi

```ts
const witnessSet = await client.signTx(unsignedTxCbor, true);
const signedTx = attachWitnessSet(unsignedTxCbor, witnessSet);
const txHash = await client.submitTx(signedTx);
```

`signTx` trả về **witness set**, không phải giao dịch đã ký. Hãy ghép nó vào giao dịch chưa ký trước khi `submitTx`; xem `attachWitnessSet` trong [Thao tác với ví](/vi/guides/wallet-operations#ký-và-gửi-giao-dịch).

`signTx` chờ người chơi phê duyệt nên có thể mất một lúc. Hãy xử lý trường hợp bị từ chối và timeout như trong [Thao tác với ví](/vi/guides/wallet-operations#ký-và-gửi-giao-dịch).

## 4. Dọn dẹp

```ts
client.destroy();
```

Gọi nó khi game tắt. Nó gỡ listener và giải phóng transport.
