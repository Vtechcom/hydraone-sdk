## Yêu cầu

- Node.js 22 trở lên cho tooling và server-side rendering.
- Một trình duyệt cho các tính năng ví.

## Cài đặt package

::code-group

```bash [npm]
npm install @hydraone-sdk/core
```

```bash [pnpm]
pnpm add @hydraone-sdk/core
```

```bash [yarn]
yarn add @hydraone-sdk/core
```

```bash [bun]
bun add @hydraone-sdk/core
```

::

`react` và `vue` là optional peer dependency. Chỉ cài chúng nếu bạn dùng các entry point cho framework (`@hydraone-sdk/core/react`, `@hydraone-sdk/core/vue`).
