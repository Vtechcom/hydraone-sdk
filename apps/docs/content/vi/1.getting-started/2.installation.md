## Yêu cầu

- Node.js 20 trở lên cho tooling và server-side rendering.
- Một trình duyệt cho các tính năng ví.
- Một extension ví CIP-30 (Eternl, Lace, Nami, Flint và các ví khác) khi bạn chạy ngoài HydraOne App Center.

## Cài đặt package

::code-group

```bash [npm]
npm install @hydraone/sdk
```

```bash [pnpm]
pnpm add @hydraone/sdk
```

```bash [yarn]
yarn add @hydraone/sdk
```

::

`react` và `vue` là optional peer dependency. Chỉ cài chúng nếu bạn dùng các entry point cho framework (`@hydraone/sdk/react`, `@hydraone/sdk/vue`).

## Bắt đầu từ template

CLI `create-hydraone-game` nằm trong cùng package và sinh ra một dự án chạy được:

```bash
npx create-hydraone-game my-game --template phaser-3
```

Các template có sẵn: `next-js`, `nuxt` và `phaser-3`.
