title: 'Giới thiệu'
description: 'HydraOne SDK là gì, cách chạy trong và ngoài App Center, và nên đọc gì tiếp theo.'
---

`@hydraone/sdk` kết nối game và dApp với HydraOne App Center trên Cardano. SDK cung cấp wallet bridge (CIP-30), đăng nhập CIP-8 với phiên JWT, storage không bị ảnh hưởng bởi các hạn chế của Safari, cùng các adapter cho React và Vue.

## Bạn nhận được gì

- **Wallet bridge.** Truy vấn địa chỉ và số dư, ký và gửi giao dịch mà không bao giờ chạm vào private key.
- **Xác thực.** Đăng nhập CIP-8 một chạm và vòng đời phiên JWT.
- **Tính năng của host.** Sự kiện theme và âm thanh, hướng màn hình, haptic và deposit modal.
- **Adapter cho framework.** `HydraOneProvider` và hook cho React và Next.js, composable và plugin cho Vue và Nuxt.
- **Chẩn đoán.** Một health check tìm ra các lỗi tích hợp thường gặp và chỉ cách khắc phục.

## Hai cách chạy

Cùng một đoạn code client chạy được trong cả hai môi trường:

| Chế độ         | Game chạy ở đâu                            | Cách truy cập ví                  |
| -------------- | ------------------------------------------ | --------------------------------- |
| **Embedded**   | Trong iframe bên trong HydraOne App Center | Qua `postMessage` tới host shell  |
| **Standalone** | Trong một tab trình duyệt thông thường     | Trực tiếp tới extension ví CIP-30 |

Xem [Kiến trúc](/vi/core-concepts/architecture) để có bức tranh đầy đủ.

## Các entry point

Một package, nhiều entry point. Chỉ import thứ bạn cần; `sideEffects: false` cho phép bundler loại bỏ phần còn lại.

| Entry point           | Nội dung                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| `@hydraone/sdk`       | Client, transport, storage adapter, auth, lỗi, kiểu dữ liệu và diagnostics. Khoảng 23 KB sau khi gzip. |
| `@hydraone/sdk/react` | `HydraOneProvider`, `useWallet`, `useHydraAuth`, `useHostStorage`.                                     |
| `@hydraone/sdk/vue`   | `useWalletBridgeClient`, `useGameAuth`, `createHydraOne` và các setter cho instance dùng chung.        |

`react` và `vue` là optional peer dependency và không bao giờ được đóng gói vào bundle.

## API reference

API reference được sinh từ các comment TSDoc trong `src/` bằng TypeDoc và không được commit. Hãy build nó bằng:

```bash
pnpm run docs:api
```

Kết quả được ghi vào `packages/sdk/docs/api/`. Mở `docs/api/index.html` trong trình duyệt.
