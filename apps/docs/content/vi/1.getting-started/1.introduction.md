title: 'Giới thiệu'
description: 'HydraOne SDK là gì, cách chạy trong và ngoài App Center, và nên đọc gì tiếp theo.'
---

`@hydraone-sdk/core` kết nối game và dApp với HydraOne App Center trên Cardano. SDK cung cấp wallet bridge (CIP-30), ký dữ liệu CIP-8, storage không bị ảnh hưởng bởi các hạn chế của Safari, cùng các adapter cho React và Vue.

## Bạn nhận được gì

- **Wallet bridge.** Truy vấn địa chỉ và số dư, ký và gửi giao dịch mà không bao giờ chạm vào private key.
- **Tính năng của host.** Sự kiện theme và ngôn ngữ, hướng màn hình và haptic.
- **Adapter cho framework.** `HydraOneProvider` và hook cho React và Next.js, composable và plugin cho Vue và Nuxt.
- **Chẩn đoán.** Một health check tìm ra các lỗi tích hợp thường gặp và chỉ cách khắc phục.

## Game chạy ở đâu

Game chạy trong một iframe bên trong HydraOne App Center. Ví nằm ở host shell, game truy cập nó qua `postMessage`, nên game không bao giờ giữ private key. Phía host do [`@hydraone-sdk/host`](/vi/core-concepts/architecture) cung cấp.

Xem [Kiến trúc](/vi/core-concepts/architecture) để có bức tranh đầy đủ.

## Các entry point

Một package, nhiều entry point. Chỉ import thứ bạn cần; `sideEffects: false` cho phép bundler loại bỏ phần còn lại.

| Entry point                | Nội dung                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| `@hydraone-sdk/core`       | Client, transport, storage adapter, lỗi, kiểu dữ liệu và diagnostics. Khoảng 22 KB sau khi gzip. |
| `@hydraone-sdk/core/react` | `HydraOneProvider`, `useWallet`, `useStorage`.                                               |
| `@hydraone-sdk/core/vue`   | `useWalletBridgeClient`, `createHydraOne` và các setter cho instance dùng chung.                 |

`react` và `vue` là optional peer dependency và không bao giờ được đóng gói vào bundle.

## API reference

API reference được sinh từ các comment TSDoc trong `src/` bằng TypeDoc và không được commit. Hãy build nó bằng:

```bash
pnpm run docs:api
```

Kết quả được ghi vào `packages/core/docs/api/`. Mở `docs/api/index.html` trong trình duyệt.
