`@hydraone-sdk/core/react` cung cấp một provider và các hook xây dựng trên core client. Cần `react` 18 trở lên làm peer dependency.

## Provider

Bọc ứng dụng một lần duy nhất. Provider tạo `WalletBridgeClient` và một storage adapter, đồng thời giữ chúng ổn định qua các lần render.

```tsx
import React from 'react';
import { HydraOneProvider, useWallet } from '@hydraone-sdk/core/react';

function Game() {
  const { isConnected, address, balanceADA, connect, disconnect } = useWallet();

  return (
    <div>
      <p>{isConnected ? `${address} (${balanceADA} ADA)` : 'Not connected'}</p>
      <button onClick={() => (isConnected ? disconnect() : connect())}>
        {isConnected ? 'Disconnect' : 'Connect'}
      </button>
    </div>
  );
}

export function App() {
  return (
    <HydraOneProvider appCenterOrigin="https://alpha.hydraone.app" autoConnect>
      <Game />
    </HydraOneProvider>
  );
}
```

### Prop của provider

| Prop                 | Kiểu                                 | Mặc định | Mô tả                                                                                          |
| -------------------- | ------------------------------------ | -------- | ---------------------------------------------------------------------------------------------- |
| `client`             | `WalletBridgeClient`                 | tự tạo   | Truyền client của riêng bạn.                                                                   |
| `storage`            | `IStorage`                           | tự tạo   | Mặc định là `SafeLocalStorageAdapter` trong trình duyệt, `InMemoryStorageAdapter` trên server. |
| `appCenterOrigin`    | `string \| string[]`                 | không có | Tạo một `PostMessageTransport` cho client mặc định. Provider hủy nó khi unmount.               |
| `options`            | `Partial<WalletBridgeClientOptions>` | không có | [Tùy chọn client](/vi/reference/client-options) bổ sung. |
| `autoConnect`        | `boolean`                            | `false`  | Chạy `client.init()` sau khi mount, chỉ trong trình duyệt.                                     |
| `autoRefreshBalance` | `boolean`                            | `true`   | Giá trị mặc định cho `useWallet`.                                                              |

Các giá trị mặc định cần biết:

- Khi có `appCenterOrigin`, provider tạo một `PostMessageTransport` và hủy nó khi unmount. Truyền một mảng để cho phép nhiều host. Nếu không có (và cũng không có `options.transport`) thì provider ném lỗi, vì client không có gì để kết nối. `client` hoặc `options.transport` bạn truyền vào không bao giờ bị hủy hộ.
- Trong Next.js App Router, bạn có thể import provider từ Server Component như `layout.tsx`; `@hydraone-sdk/core/react` đã bắt đầu bằng `"use client"`.
- Storage mặc định là `SafeLocalStorageAdapter` trên trình duyệt và `InMemoryStorageAdapter` trên server.
- `autoConnect` gọi `client.init()` trong một effect, nên không bao giờ chạy trong lúc server rendering.

## Dùng host storage relay

Để giữ dữ liệu của game trên Safari, hãy truyền vào một `HostStorageRelayAdapter` dùng chung transport với client:

```tsx
import React from 'react';
import { PostMessageTransport, HostStorageRelayAdapter } from '@hydraone-sdk/core';
import { HydraOneProvider, useWallet } from '@hydraone-sdk/core/react';

const transport = new PostMessageTransport({ appCenterOrigin: 'https://alpha.hydraone.app' });
const storage = new HostStorageRelayAdapter({ transport });

function Balance() {
  const { balanceADA, isConnected } = useWallet();
  return <p>{isConnected ? `${balanceADA} ADA` : 'Not connected'}</p>;
}

export function App() {
  return (
    <HydraOneProvider options={{ transport }} storage={storage} autoConnect>
      <Balance />
    </HydraOneProvider>
  );
}
```

## Hook

### `useWallet(options?)`

Trả về state ví (reactive) và các action.

State: `client`, `connectionState`, `isConnected`, `address`, `balanceADA` (string hoặc `null`), `balanceLovelace` (`bigint` hoặc `null`), `networkId`, `hostInfo`, `language`, `theme`.

Action: `connect`, `disconnect`, `refreshBalance`, `signTx`, `submitTx`, `signData`, `setOrientation`, `triggerHaptic`.

Option: `client`, `autoConnect` (mặc định `false`), `autoRefreshBalance` (mặc định lấy giá trị của provider, nếu không có thì là `true`). Bên ngoài `<HydraOneProvider>`, hãy truyền `client`; nếu không hook sẽ ném lỗi.

`address` là change address dạng bech32. `theme` là `'dark'` cho đến khi host báo giá trị khác. `signTx` nhận `(txCbor, { partialSign, addVkey, timeoutMs })`, xem [Thao tác với ví](/vi/guides/wallet-operations#ký-và-gửi-giao-dịch).

### `useStorage(options?)`

Trả về `storage`, `getItem`, `setItem`, `removeItem`, `clearSdkData`. Hook dùng storage của provider, trừ khi bạn truyền `storage` riêng.

### `useHydraOneContext()`

Trả về `{ client, storage, autoRefreshBalance }`. Hook ném một lỗi rõ ràng khi được dùng bên ngoài `<HydraOneProvider>`.

## Next.js (App Router)

Các hook dùng API của trình duyệt, nên hãy dùng chúng trong client component. Tạo provider trong một client component rồi render nó từ layout:

```tsx
'use client';

import React, { useMemo } from 'react';
import { PostMessageTransport, HostStorageRelayAdapter } from '@hydraone-sdk/core';
import { HydraOneProvider } from '@hydraone-sdk/core/react';

export function Providers({ children }: { children: React.ReactNode }) {
  const { transport, storage } = useMemo(() => {
    const t = new PostMessageTransport({ appCenterOrigin: 'https://alpha.hydraone.app' });
    return { transport: t, storage: new HostStorageRelayAdapter({ transport: t }) };
  }, []);

  return (
    <HydraOneProvider options={{ transport }} storage={storage}>
      {children}
    </HydraOneProvider>
  );
}
```

Server rendering là an toàn: không có gì chạm vào `window` cho đến khi một effect chạy. Số dư và địa chỉ sẽ trống trên server và chỉ được điền sau khi client kết nối, vì vậy hãy render một trạng thái trung tính trước để tránh lỗi hydration mismatch.
