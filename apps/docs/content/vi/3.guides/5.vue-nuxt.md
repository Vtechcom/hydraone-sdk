`@hydraone-sdk/core/vue` cung cấp composable bọc core client thành state reactive. Cần `vue` 3.3 trở lên làm peer dependency.

## Composable

```ts
import { computed } from 'vue';
import { useWalletBridgeClient } from '@hydraone-sdk/core/vue';

export function useGameSession() {
  const { isConnected, address, balanceADA, connect, disconnect, error } = useWalletBridgeClient({
    autoConnect: true,
  });

  const label = computed(() =>
    isConnected.value ? `${address.value} (${balanceADA.value} ADA)` : 'Offline',
  );

  return { label, connect, disconnect, error };
}
```

### `useWalletBridgeClient(options?)`

Ref: `connectionState`, `isConnected`, `address`, `usedAddresses`, `balanceADA`, `balanceLovelace` (`bigint`), `networkId`, `hostInfo`, `isAudioMuted`, `theme`, `error`. Composable cũng trả về `client`.

Action: `init`, `connect`, `disconnect`, `refreshBalance`, `refreshAddress`, `signTx`, `submitTx`, `signData`, `setOrientation`, `triggerHaptic`, `requestDepositModal`, `getPlayerProfile`.

Option: bất kỳ `WalletBridgeClientOptions` nào, cộng với `client`, `autoConnect`, `autoRefreshBalance`.

## Kết nối với App Center

Bên trong App Center, chỉ cần truyền `appCenterOrigin`, SDK sẽ tự tạo `PostMessageTransport` (và hủy nó cùng với client). Bạn không cần import `PostMessageTransport`:

```ts
const { connect } = useWalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app', // hoặc một mảng: ['https://alpha.hydraone.app', 'https://staging.hydraone.app']
});
```

Client được dùng chung, nên lần gọi composable đầu tiên quyết định option của nó. Hãy đặt `appCenterOrigin` ở lần gọi đầu tiên, hoặc đăng ký plugin bên dưới.

### Plugin (khuyên dùng, bắt buộc khi có SSR)

`createHydraOne` cấp cho mỗi app instance một client riêng. Nuxt tạo một app mới cho mỗi request, nên không có gì bị chia sẻ giữa các người dùng:

```ts
// plugins/hydra.ts
import { createHydraOne } from '@hydraone-sdk/core/vue';

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(createHydraOne({ appCenterOrigin: 'https://alpha.hydraone.app' }));
});
```

Với ứng dụng Vue thuần, gọi `app.use(createHydraOne({ appCenterOrigin: '...' }))` trước `app.mount`. Sau đó `useWalletBridgeClient()` không cần option nào. Khi unmount, plugin hủy client do nó tạo; client bạn truyền vào qua `createHydraOne({ client })` được giữ nguyên.

`createHydraOne(options)` nhận mọi [tùy chọn của client](/vi/reference/client-options) (gồm cả `appCenterOrigin`) cùng `client` (dùng một client có sẵn). Nó cung cấp client qua `HYDRA_CLIENT_KEY`. Composable tìm theo thứ tự `options.client`, rồi plugin, rồi instance dùng chung. Khi unmount, plugin hủy những gì nó đã tạo; `client` bạn truyền vào được giữ nguyên.

## Instance dùng chung

Khi không có plugin, composable dùng chung một client cho toàn ứng dụng. Client được tạo ở lần dùng đầu tiên. Lần gọi đầu tiên phải truyền `appCenterOrigin` (hoặc một `transport`), nếu không việc tạo client sẽ ném lỗi. Trên server client dùng chung không được cache: mỗi lần gọi nhận một instance mới nên không có gì rò rỉ giữa các request.

Nếu cần dùng chung transport, ví dụ với host storage relay, hãy tự tạo nó rồi đăng ký client:

```ts
import {
  WalletBridgeClient,
  PostMessageTransport,
  HostStorageRelayAdapter,
} from '@hydraone-sdk/core';
import { setSharedWalletBridgeClient } from '@hydraone-sdk/core/vue';

export const transport = new PostMessageTransport({ appCenterOrigin: 'https://alpha.hydraone.app' });
export const storage = new HostStorageRelayAdapter({ transport });

export function installHydra() {
  setSharedWalletBridgeClient(new WalletBridgeClient({ transport }));
}
```

Gọi `installHydra()` trước khi bất kỳ component nào dùng composable, ví dụ trong một Nuxt client plugin (`plugins/hydra.client.ts`) hoặc trong entry của ứng dụng. Dùng `storage` ở trên để đọc ghi dữ liệu qua host. Truyền `null` cho setter để đặt lại trong test.

## Nuxt

- Chạy phần thiết lập trong plugin `.client.ts`, vì nó cần `window` và `postMessage`.
- Các composable an toàn với SSR: chúng kiểm tra `window`, chỉ đăng ký listener sau khi mount, và gỡ listener bằng `onScopeDispose`. Hãy đăng ký `createHydraOne` như một plugin universal (không có đuôi `.client`) để mỗi request trên server có client riêng.
- Với `ssr: false` thì plugin là tùy chọn; `useWalletBridgeClient({ appCenterOrigin })` là đủ.
- Bọc phần markup phụ thuộc vào ví trong `<ClientOnly>` hoặc dùng `v-if` trên `isConnected`, để markup của server và client khớp nhau.
