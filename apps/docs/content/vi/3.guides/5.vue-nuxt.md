`@hydraone/sdk/vue` cung cấp hai composable bọc core client thành state reactive. Cần `vue` 3.3 trở lên làm peer dependency.

## Composable

```ts
import { computed } from 'vue';
import { useWalletBridgeClient, useGameAuth } from '@hydraone/sdk/vue';

export function useGameSession() {
  const { isConnected, address, balanceADA, connect, disconnect, error } = useWalletBridgeClient({
    autoConnect: true,
  });
  const { isAuthenticated, signIn, signOut, isExpired } = useGameAuth();

  const label = computed(() =>
    isConnected.value ? `${address.value} (${balanceADA.value} ADA)` : 'Offline',
  );

  async function toggleLogin() {
    if (isAuthenticated.value) await signOut();
    else await signIn({ challenge: 'server-issued-nonce' });
  }

  return { label, connect, disconnect, toggleLogin, isExpired, error };
}
```

### `useWalletBridgeClient(options?)`

Ref: `connectionState`, `isConnected`, `address`, `usedAddresses`, `balanceADA`, `balanceLovelace` (`bigint`), `networkId`, `hostInfo`, `isAudioMuted`, `theme`, `error`. Composable cũng trả về `client`.

Action: `init`, `connect`, `disconnect`, `refreshBalance`, `refreshAddress`, `signTx`, `submitTx`, `signData`, `setOrientation`, `triggerHaptic`, `requestDepositModal`, `getPlayerProfile`.

Option: bất kỳ `WalletBridgeClientOptions` nào, cộng với `client`, `autoConnect`, `autoRefreshBalance`.

### `useGameAuth(options?)`

Ref: `isAuthenticated`, `jwtToken`, `address`, `claims`, `error`, và computed `isExpired`. Composable cũng trả về `authManager`.

Action: `signIn` (cũng có thể dùng `login`), `signOut` (cũng có thể dùng `logout`), `checkSession`.

Option: `authManager`, `client`, `appCenterOrigin`, `autoCheckSession` (mặc định bật; kiểm tra phiên đã lưu sau khi mount).

## Kết nối với App Center

Bên trong App Center, chỉ cần truyền `appCenterOrigin`, SDK sẽ tự tạo `PostMessageTransport` (và hủy nó cùng với client). Bạn không cần import `PostMessageTransport`:

```ts
const { connect } = useWalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app', // hoặc một mảng: ['https://alpha.hydraone.app', 'https://staging.hydraone.app']
  fallbackToExtension: false,
});
```

Client được dùng chung, nên composable chạy đầu tiên quyết định option của nó. Hãy đặt `appCenterOrigin` ở lần gọi đầu tiên, hoặc đăng ký plugin bên dưới.

### Plugin (khuyên dùng, bắt buộc khi có SSR)

`createHydraOne` cấp cho mỗi app instance một client và một auth manager riêng. Nuxt tạo một app mới cho mỗi request, nên không có gì bị chia sẻ giữa các người dùng:

```ts
// plugins/hydra.ts
import { createHydraOne } from '@hydraone/sdk/vue';

export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(createHydraOne({ appCenterOrigin: 'https://alpha.hydraone.app' }));
});
```

Với ứng dụng Vue thuần, gọi `app.use(createHydraOne({ appCenterOrigin: '...' }))` trước `app.mount`. Sau đó `useWalletBridgeClient()` và `useGameAuth()` không cần option nào. Khi unmount, plugin hủy client do nó tạo; client bạn truyền vào qua `createHydraOne({ client })` được giữ nguyên.

`createHydraOne(options)` nhận mọi [tùy chọn của client](/vi/reference/client-options) (gồm cả `appCenterOrigin`) cùng `client` (dùng một client có sẵn) và `storage`. Nó cung cấp client và auth manager qua `HYDRA_CLIENT_KEY` và `HYDRA_AUTH_KEY`. Các composable tìm theo thứ tự `options.client`, rồi plugin, rồi instance dùng chung. Khi unmount, plugin hủy những gì nó đã tạo; `client` bạn truyền vào được giữ nguyên.

## Instance dùng chung

Khi không có plugin, cả hai composable dùng chung một client và một auth manager cho toàn ứng dụng. Chúng được tạo ở lần dùng đầu tiên với `fallbackToExtension: true` và một `SafeLocalStorageAdapter` (trên server là adapter in-memory). Nếu không có `appCenterOrigin`, client dùng chung không có transport, nên chỉ hoạt động qua cơ chế fallback sang wallet extension. Trên server các instance dùng chung không được cache: mỗi lần gọi nhận một instance mới nên không có gì rò rỉ giữa các request.

Nếu cần dùng chung transport, ví dụ với host storage relay, hãy tự tạo nó rồi đăng ký các instance:

```ts
import {
  WalletBridgeClient,
  PostMessageTransport,
  HostStorageRelayAdapter,
  GameAuthManager,
} from '@hydraone/sdk';
import { setSharedWalletBridgeClient, setSharedGameAuthManager } from '@hydraone/sdk/vue';

export function installHydra() {
  const transport = new PostMessageTransport({ appCenterOrigin: 'https://alpha.hydraone.app' });
  const client = new WalletBridgeClient({ transport, fallbackToExtension: true });
  const storage = new HostStorageRelayAdapter({ transport });

  setSharedWalletBridgeClient(client);
  setSharedGameAuthManager(new GameAuthManager({ client, storage }));
}
```

Gọi `installHydra()` trước khi bất kỳ component nào dùng các composable, ví dụ trong một Nuxt client plugin (`plugins/hydra.client.ts`) hoặc trong entry của ứng dụng. Truyền `null` cho các setter để đặt lại trong test.

## Nuxt

- Chạy phần thiết lập trong plugin `.client.ts`, vì nó cần `window` và `postMessage`.
- Các composable an toàn với SSR: chúng kiểm tra `window`, chỉ đăng ký listener sau khi mount, và gỡ listener bằng `onScopeDispose`. Hãy đăng ký `createHydraOne` như một plugin universal (không có đuôi `.client`) để mỗi request trên server có client riêng.
- Với `ssr: false` thì plugin là tùy chọn; `useWalletBridgeClient({ appCenterOrigin })` là đủ.
- Bọc phần markup phụ thuộc vào ví trong `<ClientOnly>` hoặc dùng `v-if` trên `isConnected`, để markup của server và client khớp nhau.

`npx create-hydraone-game my-game --template nuxt` sinh ra một dự án khởi đầu dùng các giá trị chung mặc định (chỉ có fallback sang wallet extension). Hãy thêm phần thiết lập `installHydra()` ở trên trước khi nhúng game vào App Center.
