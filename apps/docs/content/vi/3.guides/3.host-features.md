## Lắng nghe sự kiện từ host

```ts
import { WalletBridgeClient } from '@hydraone-sdk/core';

export function listen(client: WalletBridgeClient) {
  const offTheme = client.onThemeChanged((theme) => console.log('theme', theme));
  const offLanguage = client.onLanguageChanged((language) => console.log('language', language));
  const offCustom = client.on<{ foo: string }>('CUSTOM_EVENT', (p) => console.log(p.foo));
  return () => {
    offTheme();
    offLanguage();
    offCustom();
  };
}
```

`client.language` chứa ngôn ngữ giao diện hiện tại dưới dạng tag BCP-47 (ví dụ `'en'` hoặc `'vi'`), cũng được báo trong `hostInfo.language`. Host đẩy thay đổi bằng `host.setLanguage(tag)`. Tương tự, `client.theme` chứa `'dark'` hoặc `'light'` và host đẩy thay đổi bằng `host.notify('THEME_CHANGED', { theme })`. `client.on` là alias ngắn của `client.onHostEvent`.

Mỗi lần đăng ký đều trả về một hàm hủy đăng ký. Gọi `client.destroy()` khi game tắt; nó gỡ mọi listener.

## Điều khiển thiết bị và host

Các lệnh gọi này yêu cầu host shell thực hiện hành động:

```ts
import { WalletBridgeClient } from '@hydraone-sdk/core';

export async function device(client: WalletBridgeClient) {
  await client.setOrientation('landscape');
  await client.triggerHaptic('success');
}
```

| Lệnh gọi              | Hành vi khi ngoài iframe của App Center                                                                  |
| --------------------- | --------------------------------------------------------------------------------------- |
| `setOrientation`      | Dùng API của trình duyệt và bỏ qua lỗi.                                                 |
| `triggerHaptic`       | Dùng API của trình duyệt và bỏ qua lỗi.                                                 |

Bên trong iframe, cả hai lệnh gọi cần một client đã kết nối, nếu không sẽ bị reject với `ERR_BRIDGE_NOT_CONNECTED`. Khi ở ngoài iframe, chúng vẫn chuyển yêu cầu tới host nếu client đã kết nối.

`setOrientation` nhận `any`, `natural`, `landscape`, `portrait` và các biến thể `-primary` / `-secondary`. `triggerHaptic` nhận một preset (`light`, `medium`, `heavy`, `selection`, `success`, `warning`, `error`; mặc định `medium`), một khoảng thời gian tính bằng mili giây, hoặc một mảng pattern rung. Giá trị không hợp lệ bị reject với `ERR_INVALID_PARAMS`.

Dùng `unlockOrientation()` (tương đương `setOrientation('any')`) để nhả khóa xoay màn hình bạn đã đặt trước đó.

## Chạy phía host

App nhúng game tạo host bằng `createHost` và đưa cho nó một `HostWalletAdapter`, đây là cách SDK đọc trạng thái ví của bạn:

| Method | Trả về |
| --- | --- |
| `getChangeAddress()` | change address của ví đang kết nối, hoặc `null` |
| `getCip30Api()` | extension CIP-30 đang dùng dưới dạng `HostCip30Api`, hoặc `null` với ví nhúng |
| `fetchBalance()` / `fetchUtxos()` | tài sản và UTxO đã giải mã |
| `getNetworkId()` | `0` (testnet), `1` (mainnet) hoặc `null` |

Hãy đặt `name` cho `HostCip30Api` (ví dụ `window.cardano.eternl.name`) để game nhúng thấy tên ví thật trong `hostInfo.wallet.name` và `client.activeWalletName`. Đặt `hostName` và `networkName` trong option của `createHost`; chúng tới game dưới dạng `hostInfo.hostName` / `client.hostName` và `hostInfo.networkName`.

Báo cho host khi ví thay đổi: `host.handleAddressChange(next, previous)` khi đổi tài khoản, và `host.handleWalletConnectionChange(connected)` khi người chơi kết nối hoặc ngắt ví. Hàm thứ hai gửi `WALLET_DISCONNECTED` tới game. Bridge vẫn kết nối nên game tiếp tục chạy và phục hồi ở `ACCOUNT_CHANGED` kế tiếp.
