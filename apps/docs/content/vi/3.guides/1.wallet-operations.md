Mọi lệnh gọi dưới đây đều cần một client đã kết nối. Xem [Vòng đời kết nối](/vi/core-concepts/connection-lifecycle).

## Đọc địa chỉ và số dư

```ts
const [address] = await client.getUsedAddresses();
const balance = await client.getBalance();
```

- `getBalance()` trả về số dư dưới dạng danh sách asset (`{ unit, quantity }`, với `unit` là `lovelace` hoặc `policyId + assetNameHex`). Hook `useWallet` của React và composable `useWalletBridgeClient` của Vue đọc lovelace giúp bạn, chính xác và ở dạng `bigint`:

  ```ts
  const { balanceADA, balanceLovelace } = useWallet(); // "1234.56789" và 1234567890n
  ```

  Bên ngoài các hook, hãy giải mã `Value` CBOR bằng một thư viện Cardano.

- Các truy vấn địa chỉ như `getUsedAddresses()` trả về đúng những gì ví hoặc host trả về. Ví CIP-30 trả về hex, còn host shell có thể trả về bech32.

::tip
Hãy chuyển địa chỉ hex bằng một thư viện Bech32 trước khi hiển thị.
::

Các truy vấn khác: `getUtxos`, `getCollateral`, `getUnusedAddresses`, `getChangeAddress`, `getNetworkId`.

`getUtxos` và `getCollateral` trả về các object `Utxo` đã giải mã (`{ input, output }`), không phải CBOR hex. Hãy tự chuyển đổi bằng thư viện giao dịch nếu thư viện đó cần CBOR.

## Ký và gửi giao dịch

`signTx` trả về **witness set** (CBOR hex của một `TransactionWitnessSet`), không phải giao dịch đã ký. Điều này đúng với cả ví extension lẫn ví embedded, và host chuyển tiếp `submitTx` nguyên vẹn, nên bạn phải tự ghép witness set vào giao dịch chưa ký rồi mới gửi kết quả. SDK không cung cấp bước này; hãy dùng thư viện giao dịch Cardano của bạn, ví dụ `@emurgo/cardano-serialization-lib-browser`:

```ts
import { FixedTransaction, TransactionWitnessSet } from '@emurgo/cardano-serialization-lib-browser';

export function attachWitnessSet(unsignedTxCbor: string, witnessSetHex: string): string {
  const tx = FixedTransaction.from_hex(unsignedTxCbor);
  const vkeys = TransactionWitnessSet.from_hex(witnessSetHex).vkeys();
  for (let i = 0; vkeys && i < vkeys.len(); i++) tx.add_vkey_witness(vkeys.get(i));
  return tx.to_hex();
}
```

```ts
import { WalletBridgeClient, HydraUserRejectedError, HydraTimeoutError } from '@hydraone-sdk/core';

export async function signAndSubmit(client: WalletBridgeClient, unsignedTxCbor: string) {
  try {
    const witnessSet = await client.signTx(unsignedTxCbor, true, { timeoutMs: 60_000 });
    const signedTx = attachWitnessSet(unsignedTxCbor, witnessSet);
    const txHash = await client.submitTx(signedTx);
    return txHash;
  } catch (err) {
    if (err instanceof HydraUserRejectedError) return null;
    if (err instanceof HydraTimeoutError) throw new Error('Wallet did not respond in time');
    throw err;
  }
}
```

`signTx` và `submitTx` phải chờ người chơi, nên timeout mặc định là hai phút (`signingTimeoutMs`). Ghi đè theo từng lần gọi bằng `{ timeoutMs }`.

::note
Việc dựng giao dịch chưa ký nằm ngoài phạm vi của SDK này. Hãy dùng một thư viện giao dịch Cardano cho việc đó.
::
