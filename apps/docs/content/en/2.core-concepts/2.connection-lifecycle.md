---
title: "Connection lifecycle"
description: "How WalletBridgeClient picks a connection, connects with init() and releases it with destroy()."
---

`WalletBridgeClient` is the central class. You give it an `hostOrigin` (or your own `transport`), then call `init()`.

```ts
import { WalletBridgeClient } from '@hydraone-sdk/core';

const client = new WalletBridgeClient({
  hostOrigin: 'https://alpha.hydraone.app',
});

await client.init();
```

## How the connection is chosen

| Where the game runs                               | What `init()` does                                                                                                                             |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inside an iframe** (embedded in the App Center) | Sends `CLIENT_READY` over the transport and waits for the host to acknowledge it. A transport (or `hostOrigin`) is required.              |
| **Outside an iframe**                             | Rejects with `ERR_NOT_IN_IFRAME`, because there is no host shell to connect to.                                                                |

::note
`init()` is safe to call more than once. It resolves immediately when the client is already connected and shares one in-flight handshake.
::

## Connection state

Read the state at any time:

- `client.connectionState`: `'disconnected' | 'connecting' | 'connected'`
- `client.isConnected`
- `client.hostInfo`: what the host reported during the handshake (`hostName`, `hostVersion`, `networkName`, `wallet`, `theme`, `language`); `client.hostName` and `client.activeWalletName` are shortcuts for two of them

To react to changes, subscribe with `client.onConnectionStateChanged((state) => ...)`; it returns a function that removes the subscription.

The React hooks and Vue composables expose the same state as reactive values.

## Releasing the client

Call `client.destroy()` when the game shuts down. It removes listeners, cancels pending timers and releases the transport. A transport the client created from `hostOrigin` is destroyed with it; a transport you passed in is yours to manage.
