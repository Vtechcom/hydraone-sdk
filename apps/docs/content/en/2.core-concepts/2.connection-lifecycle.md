---
title: "Connection lifecycle"
description: "How WalletBridgeClient picks a connection, connects with init() and releases it with destroy()."
---

`WalletBridgeClient` is the central class. You give it either an `appCenterOrigin` (embedded mode) or `fallbackToExtension: true` (standalone mode), then call `init()`.

```ts
import { WalletBridgeClient } from '@hydraone/sdk';

const client = new WalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app',
  fallbackToExtension: true,
});

await client.init();
```

## How the connection is chosen

| Where the game runs                                  | What `init()` does                                                                                                                                                          |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inside an iframe** (embedded in the App Center)    | Sends `CLIENT_READY` over the transport and waits for the host to acknowledge it. A transport (or `appCenterOrigin`) is required in this mode.                              |
| **Outside an iframe**, `fallbackToExtension: true`   | Detects the wallet extensions on `window.cardano`, picks `preferredWallet` if installed (otherwise the first detected wallet) and talks to it directly.                    |
| **Outside an iframe**, without `fallbackToExtension` | Rejects with `ERR_NOT_IN_IFRAME`.                                                                                                                                           |

::note
`init()` is safe to call more than once. It resolves immediately when the client is already connected and shares one in-flight handshake.
::

## Connection state

Read the state at any time:

- `client.connectionState`: `'disconnected' | 'connecting' | 'connected' | 'error'`
- `client.isConnected`
- `client.hostInfo`: what the host reported during the handshake

The React hooks and Vue composables expose the same state as reactive values.

## Releasing the client

Call `client.destroy()` when the game shuts down. It removes listeners, cancels pending timers and releases the transport. A transport the client created from `appCenterOrigin` is destroyed with it; a transport you passed in is yours to manage.
