## Requirements

- Node.js 20 or later for tooling and server-side rendering.
- A browser for the wallet features.

## Install the package

::code-group

```bash [npm]
npm install @hydraone-sdk/core
```

```bash [pnpm]
pnpm add @hydraone-sdk/core
```

```bash [yarn]
yarn add @hydraone-sdk/core
```

::

`react` and `vue` are optional peer dependencies. Install them only if you use the framework entry points (`@hydraone-sdk/core/react`, `@hydraone-sdk/core/vue`).
