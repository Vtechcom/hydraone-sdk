## Requirements

- Node.js 20 or later for tooling and server-side rendering.
- A browser for the wallet features.
- A CIP-30 wallet extension (Eternl, Lace, Nami, Flint and others) when you run outside the HydraOne App Center.

## Install the package

::code-group

```bash [npm]
npm install @hydraone/sdk
```

```bash [pnpm]
pnpm add @hydraone/sdk
```

```bash [yarn]
yarn add @hydraone/sdk
```

::

`react` and `vue` are optional peer dependencies. Install them only if you use the framework entry points (`@hydraone/sdk/react`, `@hydraone/sdk/vue`).

## Start from a template

The `create-hydraone-game` CLI ships in the same package and scaffolds a working project:

```bash
npx create-hydraone-game my-game --template phaser-3
```

Available templates: `next-js`, `nuxt` and `phaser-3`.
