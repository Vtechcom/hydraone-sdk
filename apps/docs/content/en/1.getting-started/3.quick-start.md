This page gets you from an installed package to a signed transaction. If you have not installed the SDK yet, start with [Installation](/getting-started/installation).

## 1. Create the client

```ts
import { WalletBridgeClient, HydraBridgeError } from '@hydraone-sdk/core';

const client = new WalletBridgeClient({
  hostOrigin: 'https://alpha.hydraone.app',
});
```

- `hostOrigin` is the origin of the App Center that embeds your game. The client creates and owns the `PostMessageTransport` for you.

## 2. Connect and read

```ts
try {
  await client.init();
  const [address] = await client.getUsedAddresses();
  const balance = await client.getBalance();
  console.log(`Connected as ${address}, balance:`, balance);
} catch (err) {
  if (err instanceof HydraBridgeError) {
    console.error(`[${err.code}] ${err.message}`);
  }
}
```

::note
`getBalance()` returns a list of assets (`{ unit, quantity }`). The React and Vue helpers read the lovelace for you; see [Wallet operations](/guides/wallet-operations).
::

## 3. Sign and submit

```ts
const signedTx = await client.signTx(unsignedTxCbor, { partialSign: true, mergeWitnesses: true });
const txHash = await client.submitTx(signedTx);
```

With `mergeWitnesses: true`, `signTx` returns the signed transaction. Without it you get the CIP-30 witness set; see [Wallet operations](/guides/wallet-operations#sign-and-submit).

`signTx` waits for the player to approve, so it can take a while. Handle a rejection and a timeout as shown in [Wallet operations](/guides/wallet-operations#sign-and-submit).

## 4. Clean up

```ts
client.destroy();
```

Call it when the game shuts down. It removes listeners and releases the transport.
