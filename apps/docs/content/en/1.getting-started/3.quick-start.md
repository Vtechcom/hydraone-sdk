This page gets you from an installed package to a signed transaction. If you have not installed the SDK yet, start with [Installation](/getting-started/installation).

## 1. Create the client

```ts
import { WalletBridgeClient, HydraBridgeError } from '@hydraone/sdk';

const client = new WalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app',
  fallbackToExtension: true,
});
```

- `appCenterOrigin` is the origin of the App Center that embeds your game. The client creates and owns the `PostMessageTransport` for you.
- `fallbackToExtension: true` lets the same code work in a plain browser tab with a CIP-30 wallet extension.

## 2. Connect and read

```ts
try {
  await client.init();
  const [address] = await client.getUsedAddresses();
  const balanceCbor = await client.getBalance();
  console.log(`Connected as ${address}, balance (CBOR hex): ${balanceCbor}`);
} catch (err) {
  if (err instanceof HydraBridgeError) {
    console.error(`[${err.code}] ${err.message}`);
  }
}
```

::note
`getBalance()` returns a CBOR-encoded hex string, as CIP-30 defines it. The React and Vue helpers decode the lovelace for you; see [Wallet operations](/guides/wallet-operations).
::

## 3. Sign and submit

```ts
const witnessSet = await client.signTx(unsignedTxCbor, true);
const txHash = await client.submitTx(witnessSet);
```

`signTx` waits for the player to approve, so it can take a while. Handle a rejection and a timeout as shown in [Wallet operations](/guides/wallet-operations#sign-and-submit).

## 4. Clean up

```ts
client.destroy();
```

Call it when the game shuts down. It removes listeners and releases the transport.
