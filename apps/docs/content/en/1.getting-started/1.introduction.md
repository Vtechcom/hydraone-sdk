`@hydraone-sdk/core` connects games and dApps to the HydraOne App Center on Cardano. It gives you a wallet bridge (CIP-30) with CIP-8 data signing, storage that survives Safari restrictions, and adapters for React and Vue.

## What you get

- **Wallet bridge.** Query addresses and balances, sign and submit transactions, without ever touching private keys.
- **Host features.** Theme and language events, orientation and haptics.
- **Framework adapters.** `HydraOneProvider` and hooks for React and Next.js, composables and a plugin for Vue and Nuxt.
- **Diagnostics.** A health check that finds the common integration problems and says how to fix them.

## Where the game runs

The game runs in an iframe inside the HydraOne App Center. The wallet lives in the host shell, and the game reaches it over `postMessage`, so the game never holds a private key. The host side is provided by [`@hydraone-sdk/host`](/core-concepts/architecture).

See [Architecture](/core-concepts/architecture) for the full picture.

## Entry points

One package, several entry points. Import only what you need; `sideEffects: false` lets bundlers drop the rest.

| Entry point           | Contents                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `@hydraone-sdk/core`       | Client, transports, storage adapters, errors, types and diagnostics. About 22 KB gzipped. |
| `@hydraone-sdk/core/react` | `HydraOneProvider`, `useWallet`, `useStorage`.                              |
| `@hydraone-sdk/core/vue`   | `useWalletBridgeClient`, `createHydraOne` and shared-instance setters.           |

`react` and `vue` are optional peer dependencies and are never bundled.

## API reference

The API reference is generated from the TSDoc comments in `src/` with TypeDoc and is not committed. Build it with:

```bash
pnpm run docs:api
```

The output is written to `packages/core/docs/api/`. Open `docs/api/index.html` in a browser.
