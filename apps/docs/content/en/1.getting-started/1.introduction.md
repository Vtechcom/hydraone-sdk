`@hydraone/sdk` connects games and dApps to the HydraOne App Center on Cardano. It gives you a wallet bridge (CIP-30), CIP-8 login with JWT sessions, storage that survives Safari restrictions, and adapters for React and Vue.

## What you get

- **Wallet bridge.** Query addresses and balances, sign and submit transactions, without ever touching private keys.
- **Authentication.** One-click CIP-8 sign-in and a JWT session lifecycle.
- **Host features.** Theme and audio events, orientation, haptics and the deposit modal.
- **Framework adapters.** `HydraOneProvider` and hooks for React and Next.js, composables and a plugin for Vue and Nuxt.
- **Diagnostics.** A health check that finds the common integration problems and says how to fix them.

## Two ways to run

The same client code runs in both environments:

| Mode           | Where the game runs                          | How it reaches the wallet                          |
| -------------- | -------------------------------------------- | -------------------------------------------------- |
| **Embedded**   | In an iframe inside the HydraOne App Center  | Over `postMessage` to the host shell               |
| **Standalone** | In a normal browser tab                      | Directly to a CIP-30 wallet extension              |

See [Architecture](/core-concepts/architecture) for the full picture.

## Entry points

One package, several entry points. Import only what you need; `sideEffects: false` lets bundlers drop the rest.

| Entry point           | Contents                                                                                        |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| `@hydraone/sdk`       | Client, transports, storage adapters, auth, errors, types and diagnostics. About 23 KB gzipped. |
| `@hydraone/sdk/react` | `HydraOneProvider`, `useWallet`, `useHydraAuth`, `useHostStorage`.                              |
| `@hydraone/sdk/vue`   | `useWalletBridgeClient`, `useGameAuth`, `createHydraOne` and shared-instance setters.           |

`react` and `vue` are optional peer dependencies and are never bundled.

## API reference

The API reference is generated from the TSDoc comments in `src/` with TypeDoc and is not committed. Build it with:

```bash
pnpm run docs:api
```

The output is written to `packages/sdk/docs/api/`. Open `docs/api/index.html` in a browser.
