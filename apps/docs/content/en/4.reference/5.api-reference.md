description: "Every public export of the SDK by entry point, and how to generate the full TypeDoc reference."
---

The full API reference is generated from the TSDoc comments in `packages/core/src/` with TypeDoc. It is not committed to the repository, so build it locally from the repository root:

```bash
pnpm run docs:api
```

The output is written to `packages/core/docs/api/`. Open `packages/core/docs/api/index.html` in a browser. It covers the three entry points of `@hydraone-sdk/core`: `.`, `/react` and `/vue`.
