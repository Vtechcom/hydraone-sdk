## Listen to host events

```ts
import { WalletBridgeClient } from '@hydraone-sdk/core';

export function listen(client: WalletBridgeClient) {
  const offTheme = client.onThemeChanged((theme) => console.log('theme', theme));
  const offLanguage = client.onLanguageChanged((language) => console.log('language', language));
  const offCustom = client.on<{ foo: string }>('CUSTOM_EVENT', (p) => console.log(p.foo));
  return () => {
    offTheme();
    offLanguage();
    offCustom();
  };
}
```

`client.language` holds the current UI language as a BCP-47 tag (for example `'en'` or `'vi'`), also reported in `hostInfo.language`. The host pushes changes with `host.setLanguage(tag)`.

Every subscription returns an unsubscribe function. Call `client.destroy()` when the game shuts down; it removes all listeners.

## Device and host controls

These calls ask the host shell to act:

```ts
import { WalletBridgeClient } from '@hydraone-sdk/core';

export async function device(client: WalletBridgeClient) {
  await client.setOrientation('landscape');
  await client.triggerHaptic('success');
}
```

| Call                  | Outside the App Center iframe                                             |
| --------------------- | ------------------------------------------------------------------------- |
| `setOrientation`      | Uses the browser API and ignores failures.                                |
| `triggerHaptic`       | Uses the browser API and ignores failures.                                |

Use `unlockOrientation` to release a lock you set earlier.
