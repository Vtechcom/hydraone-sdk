All calls below need a connected client. See [Connection lifecycle](/core-concepts/connection-lifecycle).

## Read addresses and balances

```ts
const address = await client.getChangeAddress();
const balance = await client.getBalance();
```

- `getBalance()` returns the balance as a list of assets (`{ unit, quantity }`, where `unit` is `lovelace` or `policyId + assetNameHex`). The React `useWallet` hook and the Vue `useWalletBridgeClient` composable read its lovelace for you, exactly and as a `bigint`:

  ```ts
  const { balanceADA, balanceLovelace } = useWallet(); // "1234.56789" and 1234567890n
  ```

  Outside the hooks, sum the entries whose `unit` is `lovelace`.

- Address queries such as `getUsedAddresses()` return bech32 by default. Pass `{ format: 'hex' }` to get raw CIP-30 hex. The hooks' `address` is the change address; call `client.getUsedAddresses()` when you need the full list.

Other queries: `getUtxos`, `getCollateral`, `getUsedAddresses`, `getUnusedAddresses`, `getRewardAddresses`, `getChangeAddress`, `getNetworkId`.

`getUtxos` and `getCollateral` return decoded `Utxo` objects (`{ input, output }`), not CBOR hex. Convert them with your transaction library if it expects CBOR.

## Sign and submit

By default `signTx` returns the **witness set** (hex CBOR of a `TransactionWitnessSet`), as CIP-30 does, not a signed transaction. Pass `addVkey: true` to get the signed transaction instead, ready for `submitTx`. The SDK merges the wallet's vkey witnesses without re-serializing the body, so the transaction id does not change. `applyWitnessSet(txCbor, witnessSet)` does the same step on its own.

If the transaction is not valid CBOR, `signTx` rejects with `ERR_INVALID_PARAMS` before the wallet prompt. If the wallet's witness set cannot be merged, it rejects with `ERR_INVALID_RESPONSE`, and the witness set is kept in `err.details.witnessSet` so the signature is not lost.

```ts
import { WalletBridgeClient, HydraUserRejectedError, HydraTimeoutError } from '@hydraone-sdk/core';

export async function signAndSubmit(client: WalletBridgeClient, unsignedTxCbor: string) {
  try {
    const signedTx = await client.signTx(unsignedTxCbor, {
      partialSign: true,
      addVkey: true,
      timeoutMs: 60_000,
    });
    const txHash = await client.submitTx(signedTx);
    return txHash;
  } catch (err) {
    if (err instanceof HydraUserRejectedError) return null;
    if (err instanceof HydraTimeoutError) throw new Error('Wallet did not respond in time');
    throw err;
  }
}
```

`signTx` and `submitTx` wait for the player, so their default timeout is two minutes (`signingTimeoutMs`). Override it per call with `{ timeoutMs }`.

::note
Building the unsigned transaction is outside the scope of this SDK. Use a Cardano transaction library for that.
::
