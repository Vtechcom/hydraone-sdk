Hướng dẫn Bắt đầu Nhanh (15-Phút Quickstart)

Thực hiện 5 bước đơn giản để kết nối ví Cardano CIP-30 và ký giao dịch đầu tiên trong game của bạn.

1

Cài đặt Package

Cài đặt gói chính thức thông qua package manager của bạn:

bash 
pnpm add @hydraone/sdk
2

Khởi tạo WalletBridgeClient

Tạo instance và khởi động kết nối bắt tay với Host Shell:

typescript 
import { WalletBridgeClient } from '@hydraone/sdk';

const bridge = new WalletBridgeClient({
  appCenterOrigin: 'https://alpha.hydraone.app',
  handshakeTimeout: 5000
});

// Khởi chạy bắt tay handshake
await bridge.init();
3

Kết nối Ví CIP-30

Yêu cầu người dùng kết nối ví và nhận về thông tin địa chỉ ví, mạng blockchain:

typescript 
try {
  const wallet = await bridge.connect();
  console.log('Ví đã kết nối:', wallet.address);
  console.log('Mạng (0=Testnet, 1=Mainnet):', wallet.networkId);
} catch (error) {
  if (bridge.isUserRejectedError(error)) {
    console.warn('Người chơi đã từ chối kết nối ví');
  }
}
4

Truy vấn Số dư & Đơn vị BigInt ADA

Sử dụng subpath @hydraone/sdk/cardano để chuyển đổi số dư Lovelace chính xác tuyệt đối:

typescript 
import { lovelaceToAda, parseAssetValue } from '@hydraone/sdk/cardano';

const balanceCbor = await bridge.getBalance();
const parsed = parseAssetValue(balanceCbor);

console.log(`Số dư ADA: ${lovelaceToAda(parsed.lovelace)} ADA`);
5

Ký Giao Dịch Mua Vật Phẩm (CIP-30)

Gửi yêu cầu ký giao dịch an toàn tới Host Shell:

typescript 
async function buyGameItem(txCbor: string) {
  // Gửi popup duyệt ký tới ví người chơi
  const witnessSet = await bridge.signTx(txCbor, false);
  
  // Gửi giao dịch lên Cardano node
  const txHash = await bridge.submitTx(txCbor);
  console.log('Giao dịch thành công, TxHash:', txHash);
  return txHash;
}

Kiến Trúc PostMessage Bridge & Standalone Fallback

Tìm hiểu cách HydraOne SDK thiết lập kênh truyền thông an toàn giữa Game Iframe và Host Shell.

🔒 Nguyên tắc Zero-Trust: Game không bao giờ nắm giữ private key. Mọi thao tác ký ví đều được ủy quyền an toàn lên Host Shell thông qua thông điệp PostMessage có chữ ký định danh correlationId chuẩn UUIDv4.

Quy Trình 3 Pha của SDK:

  1. Pha 1: Handshake (Bắt tay khởi tạo): Gửi bản tin HYDRA_HANDSHAKE_INIT tới Host Shell. Nếu nhận được phản hồi HYDRA_HANDSHAKE_ACK, kích hoạt chế độ PostMessage. Nếu quá timeout và phát hiện extension ví trình duyệt, kích hoạt chế độ Direct Fallback.
  2. Pha 2: RPC Multiplexing: Mỗi yêu cầu CIP-30 (connect, getBalance, signTx) được gán một UUIDv4 riêng biệt. Promise chờ kết quả chỉ phân giải khi nhận được phản hồi có ID trùng khớp.
  3. Pha 3: Event Stream hai chiều: Host Shell phát các sự kiện nền (thay đổi theme, âm thanh, thay đổi tài khoản ví) xuống iframe thông qua onHostEvent().

Cẩm Nang Khắc Phục Safari ITP & Storage Relay

Giải quyết triệt để rào cản WebKit chặn Third-Party Cookies và LocalStorage trên iOS Safari và WebView.

⚠️ Rủi ro Safari ITP: Khi game chạy trong iframe cross-origin trên iOS Safari, WebKit mặc định chặn toàn bộ localStorage và document.cookie với lỗi SecurityError: The operation is insecure. Nếu không có cơ chế relay, người chơi sẽ bị mất phiên đăng nhập ngay khi reload trang.

Giải Pháp Dual-Tier Storage của HydraOne:

Lớp TieredStorageAdapter của SDK tự động kiểm tra quyền ghi vào localStorage (Tier 1). Nếu phát hiện bị chặn, SDK tự động kích hoạt **Host Storage Relay (Tier 2)**:

typescript 
// SDK tự động thực thi bên dưới khi bạn gọi getItem / setItem
await storage.setItem('auth_jwt_token', token);

// Khi phát hiện Safari ITP chặn, SDK gửi PostMessage lên App Center cha:
// window.parent.postMessage({ 
//   type: 'HOST_STORAGE_SET', 
//   key: 'hydraone:game_app_id:auth_jwt_token', 
//   value: token 
// });

API Reference: @hydraone/sdk/react

Provider và Headless Hooks chuẩn React 18/19 & Next.js.

tsx 
import { useWallet, useHydraAuth } from '@hydraone/sdk/react';

export function GameWalletWidget() {
  const { isConnected, address, balanceAda, connect, signTx } = useWallet();
  const { isAuthenticated, signIn } = useHydraAuth();

  return (
    <div>
      {isConnected ? (
        <p>Ví: {address} | Số dư: {balanceAda} ADA</p>
      ) : (
        <button onClick={() => connect()}>Kết nối Ví</button>
      )}
    </div>
  );
}

API Reference: @hydraone/sdk/vue

Headless Composables phản ứng (reactive) cho Vue 3.5+ & Nuxt 3.

vue 
<script setup lang="ts">
import { useWalletBridgeClient, useGameAuth } from '@hydraone/sdk/vue';

const { isConnected, address, balanceAda, connect } = useWalletBridgeClient();
const { isAuthenticated, signIn } = useGameAuth();

<template>
  <button v-if="!isConnected" @click="connect">Kết nối Ví Cardano</button>
  <div v-else>Ví: {{ address }} - {{ balanceAda }} ADA</div>
</template>

Tích hợp Phaser 3 Game Engine

Mô hình tích hợp WalletBridgeClient an toàn bên trong Canvas Game Scene.

typescript 
import Phaser from 'phaser';
import { WalletBridgeClient } from '@hydraone/sdk';

export class MainScene extends Phaser.Scene {
  private client!: WalletBridgeClient;

  create() {
    this.client = new WalletBridgeClient();
    this.client.init();

    const btn = this.add.text(50, 50, 'Kết nối Ví', { fontSize: '20px', color: '#00ffcc' })
      .setInteractive()
      .on('pointerdown', async () => {
        const wallet = await this.client.connect();
        btn.setText(`Ví: ${wallet.address.slice(0, 10)}...`);
      });
  }
}
